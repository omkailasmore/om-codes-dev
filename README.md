## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/omkailasmore/om-codes-dev.git
```

### 2. Enter the project

```bash
cd om-codes-dev
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open **http://localhost:3000** in your browser.
